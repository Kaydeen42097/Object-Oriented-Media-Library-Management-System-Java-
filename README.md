# Media Library Management System

A Java-based object-oriented application that allows users to organize, store, and search different types of media including books, movies, songs, video games, board games, and TV series.

This project was built to demonstrate advanced object-oriented programming concepts and data management design.

## Overview

The system functions as a console-based media database. Users can store media objects, search by title, and view detailed information through a menu-driven interface.

The project emphasizes inheritance, polymorphism, and file-based persistence.

## Features

- Store multiple media types (Books, Movies, Songs, Games, etc.)
- Search media by title
- Display detailed media information
- Add new media items dynamically
- File saving and loading system
- Organized object-oriented class hierarchy

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Inheritance and Polymorphism
- ArrayLists and Collections
- File I/O

## Key Concepts Demonstrated

- Class hierarchy design (Media superclass with multiple subclasses)
- Data serialization using custom file formats
- Modular architecture across multiple classes
- Scalable system design

## Structure

- `Media` (base class)
- `Book`, `Movie`, `Song`, `VideoGame`, `BoardGame`, `TvSeries`
- `Library` (user interface / system controller)
- `ExtFile` (file handling utilities)

## Status

Completed educational project focused on software design and OOP principles.
