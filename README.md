# Media Library

A Java application that allows users to organize, store, and search media items including books, movies, and songs. This project was developed to practice object-oriented programming concepts, data management, and user interaction through a menu-driven interface.

## Features

* Store information about books, movies, and songs
* Search for media by title
* Display detailed information about stored media
* Add new media items to the library
* Organize different media types using object-oriented design
* User-friendly menu system for navigation

## Technologies Used

* Java
* Object-Oriented Programming (OOP)
* Arrays, ArrayLists, and Collections
* Classes and Inheritance
* User Input Handling
